Sécurité & Authentification (.env)

Pour une sécurité maximale, le mot de passe pastoral n'est plus stocké dans le navigateur. Il est contrôlé côté serveur via vos variables secrètes :

ADMIN_PASSWORD Mot de passe secret
ADMIN_PIN Code PIN numérique
GITHUB_TOKEN Sauvegarde GitHub
IMGBB_API_KEY Stockage photos

💡 Pour changer de mot de passe ou de PIN à tout moment, mettez à jour la variable correspondante dans le tableau de bord Vercel (Settings > Environment Variables).
